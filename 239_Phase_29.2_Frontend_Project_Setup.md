# 3. What Is ESLint?

ESLint is a JavaScript and frontend code-quality tool.

It analyzes source code and identifies potential:

Syntax problems
Coding mistakes
Unused variables
Invalid patterns
Code-quality issues

ESLint helps maintain consistent and cleaner frontend code.

In AICIP, ESLint is used to help detect problems while developing the
React application.

# 4. What Is Oxlint?

Oxlint is another JavaScript/TypeScript linter.

It is designed to provide very fast linting and is built using the
Rust-based Oxc tooling ecosystem.
