# 1. Objective

The objective of Phase 28.9 was to verify the controller and exception
handling behavior when the authenticated user does not exist.

The test verifies that a valid authenticated request to the current-user
endpoint produces HTTP 404 Not Found when the service cannot find the
requested user.

---

# 2. Controller Endpoint

The endpoint is:

```text
GET /api/users/me
```
