# 1. Objective

The objective of Phase 29.4.4.2 is to create a reusable AICIP Button
System.

The Button System provides a consistent interaction design for the
entire frontend.

Supported button variants:

- Primary
- Secondary
- Ghost
- Danger

Supported button sizes:

- Small
- Medium
- Large

Supported states:

- Normal
- Hover
- Active
- Loading
- Disabled
- Focus
