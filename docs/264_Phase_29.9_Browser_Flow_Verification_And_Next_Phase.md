# 1. Objective

The user confirmed that the **backend → database** flow already works when
tested via **Postman** (sign in hits Spring Boot, creates/reads accounts in the
local MySQL `aicip_db`).

The goal of this phase was to prove the **same flow works through the browser**
at **`http://localhost:5173/login`** — i.e. the React frontend → Vite proxy →
Spring Boot backend (:8080) → MySQL database — and to declare the integration
**ready** for the next development phase.

---

# 2. What "Ready at That Stage" Means

The full request chain is now operational through the browser:

```text
Browser  http://localhost:5173/login   (React app served by Vite)
      │  form submit → fetch("/api/users/...)")
      ▼
Vite dev proxy  (vite.config.js → target http://localhost:8080, changeOrigin)
      ▼
Spring Boot backend  :8080   (run from IntelliJ, local profile)
      │  JPA / Hibernate
      ▼
MySQL  aicip_db  :3306   (real credentials via application-local.properties)
```

Because the frontend uses the relative base `/api` and Vite proxies it to
`:8080`, the browser never needs to know the backend port — it just works.

# 4. Live Browser-Flow Test Results

A browser-equivalent request (same origin `http://localhost:5173`, i.e. through
the same Vite proxy the browser uses) produced:

### 4.1 Frontend page loads

```
GET http://localhost:5173/login  →  HTTP 200
```

### 4.2 Create account (stored in MySQL)

```
POST http://localhost:5173/api/users/register  →  HTTP 201
```

A new user row was inserted into `aicip_db.users` (role `CITIZEN`).

### 4.3 Sign in (reads from MySQL)

```
POST http://localhost:5173/api/users/login  →  HTTP 200
role=CITIZEN | token=true | refresh=true
```

The backend returned a valid JWT access token + refresh token, proving the
account created in the browser is readable back from the database on sign-in.

# 5. How to Reproduce (IntelliJ + VS Code)

1. **Backend (IntelliJ):** Run `com.sankar.aicip.BackendApplication`.
   - `application.properties` already sets `spring.profiles.active=local`.
   - Wait for `Tomcat started on port 8080`.
2. **Frontend (VS Code):**
   ```bash
   cd frontend
   npm run dev     # → http://localhost:5173
   ```
3. **Browser:** open **http://localhost:5173/login**.
4. Click **Create Account**, fill the form, submit →
   `POST /api/users/register` → 201 (stored in DB).
5. Go back to **Sign In**, enter the same credentials → `POST /api/users/login`
   → 200 with JWT tokens → redirected to Dashboard.

> Note: if you already have a backend running on `:8080` (e.g. started from a
> console), stop it first so IntelliJ can bind the port:
> `netstat -ano | findstr :8080 | findstr LISTENING` → `taskkill /PID <pid> /F`.
