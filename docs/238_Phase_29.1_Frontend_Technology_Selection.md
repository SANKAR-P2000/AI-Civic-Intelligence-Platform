# AICIP – Phase 29.1 Frontend Technology Selection

## Status

- Phase 29 – Frontend Development: 🚧 In Progress
- Phase 29.1 – Frontend Technology Selection: ✅ Complete

---

# 1. Objective

The objective of Phase 29.1 was to finalize the frontend technology
stack before beginning frontend implementation.

---

# 2. Selected Frontend Stack

The AICIP frontend will use:

| Technology            | Selection    |
| --------------------- | ------------ |
| Frontend Framework    | React        |
| Build Tool            | Vite         |
| Programming Language  | JavaScript   |
| Styling               | CSS3         |
| HTTP Client           | Axios        |
| Routing               | React Router |
| Development IDE       | VS Code      |
| Backend Communication | REST API     |
| Authentication        | JWT          |

---

# 3. Frontend Architecture

The frontend communicates with the existing Spring Boot backend through
REST APIs.

```text
React Frontend
      ↓
Axios
      ↓
REST API
      ↓
Spring Boot 4.1.0
      ↓
Spring Security / JWT
      ↓
Spring Data JPA
      ↓
MySQL 8.0.44
```
