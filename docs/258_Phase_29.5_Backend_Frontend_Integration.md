# 1. Objective

Connect the Spring Boot backend, the React + Vite frontend, and the MySQL
database so the application works end-to-end in real time. This phase
activates the local database profile, wires the frontend to the backend
through the Vite development proxy, and verifies the full request lifecycle
from the browser UI down to the database and back.

# 3. Database Connection

## 3.1 Active Profile

The backend now activates the `local` profile by default:

```properties
spring.profiles.active=local
```

Loading `application-local.properties` provides the real MySQL credentials so
JPA/Hibernate connects to the `aicip_db` database (`ddl-auto=update`).

## 3.2 Connection Properties

| Property | Value                                  |
| -------- | -------------------------------------- |
| URL      | `jdbc:mysql://localhost:3306/aicip_db` |
| Driver   | `com.mysql.cj.jdbc.Driver`             |
| DDL      | `update`                               |
| Port     | `8080`                                 |

# 4. Frontend ↔ Backend Connection

## 4.1 Vite Development Proxy

`frontend/vite.config.js` proxies API and upload requests to the backend:

```js
server: {
  proxy: {
    "/api": { target: "http://localhost:8080", changeOrigin: true },
    "/uploads": { target: "http://localhost:8080", changeOrigin: true },
  },
}
```

## 4.2 API Base URL

`frontend/src/services/api.js` resolves the base URL from
`VITE_API_BASE_URL`, defaulting to `/api` (which uses the Vite proxy in dev):

```js
const API_BASE = import.meta.env.VITE_API_BASE_URL || "/api";
```

Documented in `frontend/.env.example`.

# 5. Real-time End-to-End Flows

| Flow                     | Frontend                                              | Backend Endpoint                 | Result                      |
| ------------------------ | ----------------------------------------------------- | -------------------------------- | --------------------------- |
| Register                 | `Register.jsx` → `authService.register`               | `POST /api/users/register`       | User created                |
| Login                    | `Login.jsx` → `authService.login`                     | `POST /api/users/login`          | JWT + refresh token         |
| Current user             | `AuthContext` → `getCurrentUser`                      | `GET /api/users/me`              | Session restore             |
| Create complaint         | `Complaints.jsx` → `complaintService.createComplaint` | `POST /api/complaints`           | Complaint created (CITIZEN) |
| Track complaint (public) | `Home.jsx` / `Complaints.jsx`                         | `GET /api/complaints/track/{id}` | Public tracking             |
| My complaints            | `Dashboard.jsx` → `getMyComplaints`                   | `GET /api/complaints/my`         | Citizen list                |
| Citizen stats            | `Dashboard.jsx` → `getMyStats`                        | `GET /api/dashboard/mystats`     | Citizen dashboard stats     |
| Admin stats              | `Dashboard.jsx` → `/admin/dashboard`                  | `GET /api/admin/dashboard`       | Admin overview              |
| Admin complaints         | `Dashboard.jsx` → `adminGetAllComplaints`             | `GET /api/admin/complaints`      | Admin list                  |
