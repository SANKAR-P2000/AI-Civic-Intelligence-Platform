# Phase 23.4 – Resource Not Found Exception

## Objective

Create a custom exception for resources that are not found.

---

## Purpose

Return HTTP 404 instead of generic runtime errors when requested resources do not exist.

---

## Exception

ResourceNotFoundException

---

## HTTP Status

404 Not Found

---

## Response

ErrorResponse

---

## Benefits

- Cleaner service layer
- Better API design
- Meaningful error messages
- Consistent error handling

---

## Status

Completed
