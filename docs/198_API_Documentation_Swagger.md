# Phase 25.1 – API Documentation (Swagger)

## Objective

Integrate SpringDoc OpenAPI into the AI Civic Intelligence Platform.

---

## What is Swagger?

Swagger is an interactive API documentation tool.

It automatically generates documentation for REST APIs and provides a web interface for testing endpoints.

---

## Benefits

- Interactive API testing
- Auto-generated documentation
- Easier frontend integration
- Better developer experience
- Professional portfolio

---

## Technologies

- Spring Boot
- SpringDoc OpenAPI
- Swagger UI

---

## Features

- REST endpoint documentation
- Request examples
- Response examples
- JWT authentication support
- API grouping

---

## Swagger URL

After configuration:

http://localhost:8080/swagger-ui/index.html

OpenAPI JSON:

http://localhost:8080/v3/api-docs
