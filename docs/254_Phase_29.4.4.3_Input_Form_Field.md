# 1. Objective

Create a reusable AICIP Input / Form Field component.

The component will provide a consistent form design for:

- Login
- Registration
- Complaint submission
- Profile
- Search
- Filters
- Admin forms
- Citizen forms

The design follows the AICIP glassmorphism UI system.

The component will support:

- Text input
- Email input
- Password input
- Number input
- Search input
- Textarea
- Label
- Placeholder
- Helper text
- Error message
- Disabled state
- Required state
- Focus state
