# 1. Objective

The objective of Phase 29.2.5 was to configure the React frontend with
environment-specific configuration while keeping local configuration
separate from source code and GitHub-tracked files.

The primary configuration is the backend REST API base URL.

---
# 2. .env

The local .env file contains the local frontend configuration:

VITE_API_BASE_URL=http://localhost:8080/api

# Purpose of .env

A .env file stores environment-specific configuration separately
from application source code.

In AICIP, it provides the backend API base URL to the frontend.

The application can access the value through:

import.meta.env.VITE_API_BASE_URL

This allows the backend URL to be changed for different environments
without changing the frontend source code.

Example:

Local:
http://localhost:8080/api

Production:
https://production-api.example.com/api
