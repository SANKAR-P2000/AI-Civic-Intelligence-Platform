# 1. Objective

The objective of Phase 29.3.1 is to define the frontend architecture
before implementing application routing.

The architecture separates pages, reusable components, layouts,
routing, API services, hooks, utilities, and assets.

This provides a maintainable structure for the AICIP React frontend.



# Architecture Relationship

The planned frontend flow is:

User
  │
  ↓
React Router
  │
  ├── Public Pages
  │
  └── Protected Pages
          │
          ↓
      Components
          │
          ↓
       Services
          │
          ↓
    Spring Boot REST API
