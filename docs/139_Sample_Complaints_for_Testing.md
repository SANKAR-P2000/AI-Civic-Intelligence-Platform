# Sample Complaint 1 – Garbage Overflow

## Scenario

Garbage has not been collected for several days near a public park.

### Request Body

```json
{
  "title": "Garbage Overflow Near Public Park",
  "description": "Garbage has not been collected for the past four days, causing a foul smell and attracting stray animals.",
  "category": "GARBAGE",
  "location": "Anna Nagar, Chennai",
  "imageUrl": "garbage-overflow.jpg"
}
```
