# 1. Objective

Create a reusable AICIP theme system supporting:

- Night Mode
- Daylight Mode
- Theme switching
- Persistent theme selection
- Glassmorphism in both themes
- Responsive compatibility
- Future component compatibility

The same UI components must work in both themes.

The project must NOT create separate pages for each theme.

Instead:
# Create Theme Utility File

- New-Item -ItemType File -Force src\utils\theme.js

# Purpose:

- Creates the central theme management utility.

```text
One React application
        ↓
One component system
        ↓
Theme tokens change
        ↓
Night / Day appearance
```
