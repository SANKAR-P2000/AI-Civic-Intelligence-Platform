# 1. Objective

The objective of Phase 28.6 was to verify the controller behavior when
the login request is valid but the supplied credentials are invalid.

This is different from validation failure.

Phase 28.5 tests invalid request data.

Phase 28.6 tests authentication failure.

---

# 2. Scenario

The test uses a structurally valid login request:

```text
Email:
sankar@example.com

Password:
WrongPassword123
```
